# Public repository audit

This repository is the clean public deployment version of the bilingual static website. The complete local research and development history is separate and is not part of this public repository.

The public history was created from an explicit allowlist. It contains the public website source, reviewed static JSON snapshots, web-display WebP derivatives, and the GitHub Pages workflow.

It does not contain SQLite databases, original high-resolution images, Excel source workbooks, research working files, backups, original deployment archives, local environment files, or credentials.

The committed WebP files are reproducible display derivatives. They do not replace the locally preserved source images. The committed JSON files are read-only publication snapshots and do not replace the local research database.

Before the initial public commit, the complete public tree was checked for forbidden file extensions, local absolute paths, research-source paths, unexpected data fields, and credential patterns. No real secret was found. The public JSON audit found no local paths, administrator fields, passwords, tokens, email addresses, private comments, or review notes.
